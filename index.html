Сайт представляет собой инструмент для расчета площади контура на изображении.

Этот сайт может быть полезен студентам при выполнении лабораторных работ по физике.

Обрезка и настройка квадрата

Настройки маски

Площадь: 0.00

Обрезка изображения

Настройте обрезку изображения с помощью ползунков.

Редактирование изображения

Закрасьте лишние элементы изображения черным цветом.

Инструкция по использованию

1. Сделайте фото петли на экране осциллографа (чем ровнее будет сделано фото, тем точнее будет результат вычислений).
2. Загрузите изображение, нажав на кнопку "Выбрать файл".
3. Нажмите "Редактировать изображение".
4. В первом окне настройте обрезку границ изображения.
5. Во втором окне закрасьте черным цветом ненужные участки изображения.
6. Настройте размер прямоугольника и параметры маски на главной странице.
7. Величина площади будет отображаться под изображением.
